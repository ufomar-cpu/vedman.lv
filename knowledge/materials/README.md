## What this is

Each subfolder is a **material digital passport** — not a product SKU page. Passports feed website, SEO, AI, WhatsApp, PDF, and channel snippets from one source.

**Master plan:** [MATERIAL_CENTER_MASTER_PLAN.md](../../MATERIAL_CENTER_MASTER_PLAN.md)

## Folder rules

1. One slug = one folder = one primary fraction/variant  
2. `material.md` is the passport (30 sections)  
3. `faq.md` is material-specific FAQ  
4. `images/` holds real VEDMAN WEBP assets only  
5. Technical numbers require verification — else `[TBD]`  
6. Update [MATERIAL_INDEX.md](MATERIAL_INDEX.md) status when passport changes
