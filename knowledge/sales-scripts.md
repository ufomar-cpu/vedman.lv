## Inbound phone — new customer

```
"Sveiki, VEDMAN, [vārds]. Ko Jums vajag piegādāt?"
→ Materiāls, frakcija, tonnas (vai palīdzība aprēķināt)
→ Adrese
→ Kad vajag
→ "Sagatavošu piedāvājumu un atsūtīšu WhatsApp / nosaukšu cenu."
```

## Inbound — returning customer

```
"Sveiki! Prieks atkal dzirdēt. Tas pats materiāls un adrese?"
→ Ātra apstiprināšana
→ "[TBD: cena šodien]"
```

## WhatsApp quote follow-up

```
"Sveiki! Paldies par pieprasījumu.
Materiāls: [X], [frakcija], [Y] t
Adrese: [Z]
Piegāde: [TBD: datums]
Cena: [TBD — tikai pēc apstiprināšanas]
Apstipriniet, lūdzu."
```

## Tonnes education (gentle)

```
"Šķembas nododam pa svaram tonnās — tā saņemat tieši to daudzumu,
ko sveram. Ja zināt tikai kubikmetrus, palīdzēsim aprēķināt aptuveni."
```
